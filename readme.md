**Luminbell** es una plataforma e-commerce interactiva, moderna y de alta conversión diseñada para una marca ficticia de cuidado personal masculino. El proyecto destaca por su estética *Dark Mode* sofisticada, acentos dorados, efectos de *glassmorphic backdrop blur*, animaciones fluidas y una experiencia de usuario (UX/UI) highly pulida.

---

## ✨ Características Principales

- 🎨 **Diseño Visual de Lujo**: Paleta basada en obsidiana/charcoal (`#121212`) con detalles en oro bruñido (`#D4AF37`) y tipografía editorial (*Cormorant Garamond* e *Inter*).
- 🔍 **Filtrado y Búsqueda en Tiempo Real**: Catálogo interactivo de productos con filtrado dinámico por categorías (*Cabello, Barba, Cuidado Facial, Champús*) y barra de búsqueda en tiempo real.
- 🛒 **Carrito de Compras (Side Drawer)**: Desplegable lateral fluido con gestión de cantidades, cálculo de envío gratis y cálculo de subtotal.
- 👁️ **Ficha de Producto (Quick View Modal)**: Visualización detallada de especificaciones (fijación, brillo, aroma, tipo de piel) y adición directa al carrito.
- 💳 **Checkout Modal de Compra**: Simulación completa de proceso de pago con opciones de Tarjeta, PayPal y Bizum.
- 📜 **Social Proof & Manifiesto**: Carrusel de testimonios de clientes verificados y modal de la historia de la marca.
- 📱 **100% Responsivo**: Adaptado para dispositivos móviles, tablets y monitores de alta resolución.

## 🚀 Cómo Ejecutar Localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/JLTAPIC/LUMENBELLWEB.git
   cd LUMENBELLWEB
   ```

2. Ejecuta el servidor Node.js integrado:
   ```bash
   node server.js
   ```

3. Abre tu navegador e ingresa a:
   ```
   http://localhost:3000/
   ```
